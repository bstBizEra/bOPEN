# AGENTS.md — Machine-readable contracts

This file supplements the root [`AGENTS.md`](../AGENTS.md). Root rules remain mandatory.

## Directory purpose

Contracts are authoritative only when approved and versioned. Draft files must include `status: draft`. Breaking changes require a new major version or approved migration policy. Generated code is derived output and must identify its source contract.

## Required completion evidence

- applicable artifact, requirement, ADR and work-package IDs;
- tests or validation appropriate to the directory;
- documentation/contract updates;
- security and clean-room declaration;
- residual risks and blocked decisions.
