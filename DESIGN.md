# DESIGN.md

The controlling design specification is:
`docs/08-design/BOPEN-DESIGN-001_v0.1.md`.

Design priorities:

1. Clearly distinguish user, tenant and platform context.
2. Make active tenant context visible.
3. Show entitlement, permission and policy restrictions accurately.
4. Preserve tenant branding within platform-defined accessibility and security bounds.
5. Design loading, empty, error, suspended, restricted and support-access states.
6. Require responsive and accessible portal behavior.
7. Treat module navigation as a registered contribution, not hard-coded coupling.
8. Keep human approval and agent activity visibly distinguishable.
