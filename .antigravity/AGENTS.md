# Antigravity adapter for bOPEN

The repository root `AGENTS.md` governs this harness. Resolve shared skills
through `docs/registers/skill-registry.json` and route them with
`.agents/SKILL-ROUTING.md`. Installed candidates remain inactive. Run
`python tools/validate_skill_registry.py --check-discovery antigravity` and
stop on unknown, drifted, inactive, or unauthorized explicit-only skills.
