# Module Contract

A valid module contains:

```text
module.yaml
AGENTS.md
README.md
REQUIREMENTS.md
DESIGN.md
ARCHITECTURE.md
SECURITY.md
DATA.md
API.md
EVENTS.md
PERMISSIONS.md
ENTITLEMENTS.md
MIGRATIONS.md
TESTING.md
OPERATIONS.md
CHANGELOG.md
src/
tests/
```

Required manifest fields are provided in `templates/module.yaml`.
