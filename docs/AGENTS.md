# AGENTS.md — Controlled documentation

This file supplements the root [`AGENTS.md`](../AGENTS.md). Root rules remain mandatory.

## Directory purpose

Use document IDs, statuses and templates. Distinguish normative, informative and draft content. Update the manifest, status register and traceability matrix with controlled changes. Avoid claims not supported by evidence or approved decisions.

## Required completion evidence

- applicable artifact, requirement, ADR and work-package IDs;
- tests or validation appropriate to the directory;
- documentation/contract updates;
- security and clean-room declaration;
- residual risks and blocked decisions.

## Proposal isolation

Documents marked `PROPOSED_NON_EFFECTIVE` or `DRAFT_CANDIDATE_NOT_ACTIVE`
remain advisory. Their presence, review outcome, technical recommendation or
template does not activate a control or create authority.

Technical-review artifacts must distinguish:

- maker result;
- independent checker disposition;
- integrated-candidate evidence;
- attributable human gate decision;
- canonical state transition.

Do not translate a technical vote, panel result or model consensus into
approval, signing, register mutation, ref movement or phase completion.
