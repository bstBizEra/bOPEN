# Evidence Matrix

| bOPEN concept | Required BoxyHQ traces | Minimum level | Reviewer |
|---|---|---:|---|
| Platform | setup, integrations, operational boundaries | E2 | Architect |
| Principal | user/account/session/API key | E3 | Identity/Security |
| Tenant | team create/update/delete/settings | E3 | Tenant Architect |
| Membership | owner create, invite accept, remove/leave | E4 | Tenant + Security |
| Context | team selection and server-side resolution | E4 | Authorization |
| Authorization | permission checks and negative cases | E4 | Security |
| Entitlement | billing/subscription and access effect | E3 | Commercial Architect |
| Capability | resource/action inventory and gaps | E2 | Module Architect |
| Audit | actor/team/action coverage and failure mode | E3 | Security/Audit |
| Events | event inventory, delivery and idempotency | E3 | Integration Architect |
