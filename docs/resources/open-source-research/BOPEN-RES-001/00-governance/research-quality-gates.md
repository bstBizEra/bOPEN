# Research Quality Gates

## G0 — Research authorization

Pass when scope, roles, environments and compliance owner are assigned.

## G1 — Source integrity

Pass when repository, commit, license and upstream status are independently verified.

## G2 — Reproducibility

Pass when a second operator can clone, configure and execute the baseline using recorded instructions.

## G3 — Lifecycle traceability

Pass when account/team/member/invitation flows are traced to schema changes and events.

## G4 — Access traceability

Pass when team context and permission checks are demonstrated for positive and negative cases.

## G5 — Security and commercial review

Pass when dependency, secret, SSO/SCIM, audit, webhook, API-key, billing and entitlement gaps are reviewed.

## G6 — Architecture synthesis

Pass when each proposed bOPEN requirement is supported by evidence and assigned ADOPT/ADAPT/REJECT/DEFER.

## G7 — Clean-room release

Pass when implementation inputs contain no upstream code and provenance review is complete.
