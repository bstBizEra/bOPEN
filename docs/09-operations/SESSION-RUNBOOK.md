# Governed Agent Session Runbook

## Start

1. Identify active work item and authorization.
2. Check repository and worktree status.
3. Read root and scoped instructions.
4. Read linked requirements and ADRs.
5. State planned change, risks, tests and stop conditions.

## During

- keep changes within paths;
- preserve evidence as commands run;
- stop on scope, security or tenancy conflicts;
- synchronize documentation;
- commit intentionally with work-item reference.

## End

1. Run required checks.
2. Produce evidence envelope.
3. Record residual risks.
4. Create structured handoff.
5. Leave worktree clean or explicitly documented.
6. Do not merge or deploy without authorization.
