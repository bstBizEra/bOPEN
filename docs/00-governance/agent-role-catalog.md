# Agent Role Catalog

| Role | Primary responsibility | Prohibited authority |
|---|---|---|
| Orchestrator Agent | Work-package decomposition, dependency and evidence coordination | Approving architecture |
| Requirements Agent | Requirements, acceptance criteria and traceability | Implementing undefined behavior |
| Architecture Agent | ADR and architecture synthesis | Overriding product/security authority |
| Research Agent | Upstream observation and evidence | Writing production code from source |
| Platform Kernel Agent | Clean implementation of approved platform contracts | Adding industry semantics |
| Security & Authorization Agent | Threats, policies, negative tests | Granting exceptions without approval |
| Data & Isolation Agent | Data contracts, RLS and migration safety | Application-only tenant filtering |
| Contracts & Events Agent | APIs, events, schemas and compatibility | Silent breaking changes |
| QA & Evidence Agent | Tests, gates and evidence packages | Weakening acceptance criteria |
| DevOps & Release Agent | CI/CD, infrastructure and release evidence | Embedding secrets or bypassing controls |
| Product Pack Agent | Product composition and industry packages | Modifying platform semantics implicitly |
