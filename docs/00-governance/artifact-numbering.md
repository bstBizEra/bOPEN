# Artifact Numbering

Format: `BOPEN-<DOMAIN>-<NNN>`. Domains include `REQ`, `ARCH`, `TENANT`, `AUTHZ`, `ENT`, `MOD`, `PARTY`, `SEC`, `BOOT`, `RES`, `OPS`, `DATA`, `API` and `EVT`. Work packages use `<PROGRAM>-P<PHASE>-<NN>`. ADRs use `ADR-<NNNN>`.

## GOV-P0-01 draft extension

`GOAL` identifies controlled program-goal baselines and `GOV` identifies cross-program governance controls. These candidate domains are used by BOPEN-GOAL-001 and BOPEN-GOV-001 and remain draft until the applicable authority approves DEC-0010.
