# bOPEN Authority Matrix

| Decision | Propose | Review | Approve | Execute |
|---|---|---|---|---|
| Goal and portfolio priority | Product Authority | Architecture/Delivery | Sponsor | Program team |
| Requirement baseline | Product | Architecture/Security/Data | Product Authority | Delivery |
| Architecture decision | Architect | Security/Data/Operations | Architecture Authority | Makers |
| Technology freeze | Architecture | Security/Operations/Delivery | Architecture Authority | Platform team |
| Work-item authorization | Module owner | Checker | Delivery Authority | Assigned maker |
| Security exception | Owner | Security + Architecture | Human Security Authority | Control owner |
| Tenant-isolation verdict | Verifier | Security/Conformance | Human Conformance Authority | Release team |
| Production release | Release coordinator | All required authorities | Human Release Authority | Operations |
| Skill promotion | Skill owner | Evaluator/Security | SkillsHub Authority | Publisher |

Agents may fill proposer, maker, checker or verifier roles only when registered and
explicitly assigned. Final D3 approval remains human.
