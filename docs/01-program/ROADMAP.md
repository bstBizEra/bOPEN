# bOPEN Roadmap

## P0 — Governed skeleton

Repository, CI, governance, evidence, principal/tenant skeleton, RLS proof, module
registry shell, portal shell and audit/outbox foundations.

## P1 — Multi-tenant kernel

Identity adapter, tenant and membership lifecycles, active context, authorization,
support grants, audit and outbox.

## P2 — Module platform

Product/module/capability/permission registries, entitlements, module SDK, registered
events, developer surfaces and module certification.

## P3 — Common business foundation

Party, organization, legal entity, contact, address, location, document, asset, money,
measurement, classification, comment, approval and notification foundations.

## P4 — bPro reference

Project/work capability package, portal composition, complete reference flow, module
factory and conformance evidence.

## P5–P8

Industry products, commercial kernel, isolation profiles, scale, agents and automation
after prior gates demonstrate readiness.
