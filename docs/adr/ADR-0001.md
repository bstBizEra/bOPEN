# ADR-0001 — bOPEN is a platform kernel, not an industry application

**Status:** Accepted  
**Date:** 2026-07-12  
**Owner:** Architecture Authority

## Context

bOPEN requires a durable decision on this topic before implementation or repository evolution.

## Decision

Keep platform domains industry-neutral and compose products through packages.

## Consequences

- The decision constrains implementation and testing.
- Changes require a superseding ADR.
- Draft/proposed decisions do not authorize production behavior.

## Evidence

BOPEN-RES-001 and the bOPEN architecture baseline.
