# bOPEN Glossary

| Term | Definition |
|---|---|
| Platform | Governed operating environment, control plane, products, policies and shared services. |
| Principal | Human, service, application, device, agent or system identity capable of acting. |
| Identity | Authentication-linked representation used to establish a principal. |
| Party | Real-world person or organization participating in business relationships. |
| Tenant | Commercial, policy, security and data-isolation boundary. |
| Organization | Business structure inside or associated with a tenant. |
| Legal Entity | Legally incorporated or recognized organization. |
| Membership | Governed relationship between a principal and a tenant or scoped container. |
| Context | Validated tenant, organization, workspace and resource scope for a decision. |
| Authorization | Decision whether a principal may perform an action on a resource in context. |
| Entitlement | Commercial or administrative right of a tenant to use a product, feature, quota or capacity. |
| Capability | Versioned action/resource contract exposed by a product or module. |
| Module | Governed package that registers capabilities, resources, dependencies and events. |
| Feature Flag | Operational rollout decision, separate from entitlement. |
| RLS | Row-level security used as a database enforcement layer. |
| ReBAC | Relationship-based access control. |
| Clean Room | Separation process that converts research evidence into independent specifications and implementation. |
