## Readiness report

BOOT-P0-12 readiness evidence is generated by `python tools/report_bootstrap_gates.py --write artifacts/validation/bootstrap-gate-readiness.md`.

The report is evidence only. It does not approve B7 or authorize production platform kernel implementation.

After EVD-BOOT-001 and EVD-BOOT-002 were generated, the refreshed readiness report is `artifacts/validation/bootstrap-gate-readiness-after-evidence.md`.
