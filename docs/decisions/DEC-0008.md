# DEC-0008 - Stable repository protection capability

**Status:** Proposed
**Owner:** Engineering Authority
**Due date:** Before B7 approval

## Question

How will required stable-branch protection be enforced while `bstBizEra/bOPEN` is private and the current GitHub plan does not expose branch protection or repository rulesets?

## Options

1. Upgrade the GitHub account to a plan supporting protection for private repositories.
2. Keep GitHub as the stable mirror and enforce working-branch protection in private local bGitea, with manual GitHub release publication evidence.
3. Make the GitHub repository public after separate legal, license, and product approval.

## Recommendation

Use option 2 for bootstrap closure, then reassess option 1 before production development. Option 3 is not compatible with the current all-rights-reserved license posture without a separate approval.

## Impact

BOOT-P0-08 and B7 cannot be approved from GitHub protection evidence alone under the current repository visibility and account capability. Local bGitea activation or a GitHub plan change is required.

## Decision and approver

Pending Engineering Authority approval.
