## Decision required

Three linked dispositions:

1. **Adopt authority matrix v0.2** (`docs/00-governance/AUTHORITY-MATRIX-0.2.0-PROPOSAL.json`) as the replacement content of `docs/00-governance/registers/AUTHORITY-MATRIX.json`, adding the three actions the PG-G0 docket records as absent: `APPROVE_GOVERNANCE_BASELINE` (BOPEN-GOV-001), `APPROVE_PROGRAM_REGISTERS` (the seven program registers) and `PASS_PG_G0`.
2. **Reconcile the `ACCEPT_WORK_ITEM` concurrence conflict.** BOPEN-GOV-001 prose requires "Owning artifact authority" concurrence; matrix v0.1 records an empty list. The proposal aligns machine to prose with the parameterized role `Owning Artifact Authority`, resolved per subject artifact (for GOV-P0-01 the owning artifact authority is the Product Authority, matching PG-G0-DEC-002 as prepared).
3. **Adopt the authority identity register** (draft at `docs/00-governance/AUTHORITY-IDENTITY-REGISTER-DRAFT.json`, schema `contracts/governance/authority-identity-register.schema.json`). On approval the content moves to the exact path the docket validator requires — `docs/00-governance/registers/AUTHORITY-IDENTITY-REGISTER.json`. The draft is deliberately kept off that path: the docket test harness prefers real repository files over its temp fixtures, so occupying the bound path before approval breaks five negative tests (fixture fragility disclosed to the GOV-P0-02 maker in EVD-GOV-004).

## Options

1. Adopt all three as drafted (concurrence follows prose).
2. Adopt the new actions but amend BOPEN-GOV-001 prose to drop work-item concurrence instead (machine wins); requires a BOPEN-GOV-001 revision.
3. Reject and direct a different decomposition of actions or identity binding.

## Recommendation

Option 1. Prose is the higher-order source under the source-of-truth hierarchy; the machine register should follow it. The three new actions use the same fail-closed shape as existing entries (`self_approval_allowed: false`, `evidence_required: true`, expiry required).

## Constraints and non-effects

- The proposal file does not replace the bound v0.1 matrix; the PG-G0 docket binds the v0.1 SHA-256 at commit `c893062` and stays valid until a revised docket rebinds v0.2.
- Adoption requires bumping `contracts/governance/authority-matrix.schema.json` to accept the `0.2.0-draft` schema URI (or an approved release version) in the same change.
- The identity register is `draft` with a single `pending` record; nothing in this decision approves any identity, register, gate or authority.
- Solo-operator concentration is disclosed in the register's `independence_disclosure`; all five concurrence roles collapse to one person, so concurrence provides procedural attribution rather than inter-human independence.
