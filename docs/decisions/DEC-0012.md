## Decision required

Choose attributable, controlled handling for the required root paths `Roadmap.md`, `Master_Standards.md`, `Progress_Log.md`, `Backlog.md`, and `Recap_Today.md`, and reconcile literal append-only history with deterministic generated manifests.

## Options

1. Create the exact root paths as controlled append-only indexes/ledgers whose contents reference only approved sources.
2. Formally designate existing controlled equivalents and add non-authoritative root locators.
3. Amend the replacement instructions through an attributable human decision.

For manifests:

1. Permit deterministic replacement of generated manifests while retaining Git history; or
2. Require immutable versioned snapshots and an index.

## Recommendation

Use exact root locators/append-only ledgers plus versioned manifest snapshots until authorities explicitly approve deterministic replacement. Do not infer that similarly named files are equivalent.
