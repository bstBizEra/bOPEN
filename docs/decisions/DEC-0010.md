# DEC-0010 — Adopt Program Goal v0.2 and Namespaced Lifecycle Model

**Version:** 0.1
**Status:** Proposed
**Owner:** Product and Architecture Authorities
**Issued:** 2026-07-21
**Work package:** GOV-P0-01

## Decision required

Decide whether to approve `BOPEN-GOAL-001` v0.2, its outcomes and targets, and the `PG-*`, `RM-*`, `BOOT-B*`, `RES-G*`, `RES-R*` and `OUT-*` presentation namespaces.

## Context

The supplied program goal uses bare `G0` and `P0` while the repository already uses G0-G7 for research, B0-B7 for bootstrap, Phase 0-4 for the roadmap, R0/R1 for research waves and P0 inside work-package IDs. An unqualified status can therefore misrepresent evidence or authority.

## Proposed decision

1. Adopt BOPEN-GOAL-001 only after Product Authority approval and required concurrence.
2. Use the presentation aliases in `program-lifecycle-crosswalk.md` without renaming existing artifacts.
3. Require all cross-namespace status claims to state namespace, artifact/version, evidence SHA, disposition and authority.
4. Keep every program gate `NOT_READY` until its own approved evidence contract is satisfied.
5. Preserve the existing implementation gate: BOOT-B7, RES-G7, applicable normative approvals, accepted contracts/tests and an accepted implementation work package are all separate prerequisites.

## Alternatives

- Keep bare lifecycle labels: rejected as ambiguous and unsafe.
- Rename existing historical artifacts: rejected because it would break stable IDs and evidence references.
- Treat the program lifecycle as identical to the roadmap: rejected because the mappings are not one-to-one and PG-C0 has no roadmap equivalent.

## Consequences

Approval would create a controlled program-goal baseline and deterministic vocabulary. It would not pass PG-G0, BOOT-B7 or any research gate, select technology, certify a module, authorize a release or authorize production implementation.

## Decision and approver

Pending Product and Architecture Authority decision; Security and Data concurrence required for affected outcomes.
