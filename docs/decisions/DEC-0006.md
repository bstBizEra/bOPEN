# DEC-0006 - GitHub stable history reconciliation

**Status:** Proposed
**Owner:** Engineering Authority
**Due date:** Before stable GitHub publication

## Question

How should the local bootstrap history be reconciled with the unrelated existing `github/main` history without bypassing protected-branch review?

## Options

1. Create a reconciliation branch from `github/main`, cherry-pick the approved bootstrap commits, resolve the initial-file conflicts once, and merge through a protected pull request.
2. Merge the unrelated histories and retain both roots, accepting a noisier permanent history.
3. Replace GitHub `main` with the local history after an explicit repository-replacement approval and backup.

## Recommendation

Use option 1. It preserves the existing stable branch, avoids a force-push, and gives CODEOWNERS and CI a normal review point.

## Impact

Stable publication remains blocked until this decision is approved. Local Phase 0 documentation, tooling, contract, and evidence work may continue.
