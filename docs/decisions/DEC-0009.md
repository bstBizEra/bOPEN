# DEC-0009 - External ephemeral research workspace

**Status:** Approved
**Owner:** bOPEN Architecture Authority
**Due date:** Before BOPEN-RES-001 G0 approval

## Question

Where may physical upstream clones exist when `research/AGENTS.md` names `research/upstream/` as the research zone but the clean-room validator requires that repository path to contain no upstream source?

## Options

1. Clone inside the bOPEN worktree under `research/upstream/` and rely only on ignore rules.
2. Keep `research/upstream/` as the logical governance boundary and marker, while storing physical clones and raw evidence in an approved external ephemeral workspace.
3. Permit operator-selected clone locations without a fixed boundary.

## Recommendation

Use option 2. On Windows, physical upstream source and raw logs belong under `C:\laragon\www\bopen-research\<operator-run>`, outside the bOPEN Git worktree. A non-Windows operator must receive and set a platform-specific absolute `BOPEN_RESEARCH_APPROVED_ROOT`; the shell workflow fails closed when it is absent. Only sanitized findings, checksums, decisions, and evidence receipts may enter bOPEN.

## Impact

The clone bootstrap must validate the external workspace root, disable ambient credential prompting, preserve detached pinned source, and keep raw output outside bOPEN. `research/upstream/` remains source-free and is checked by `tools/check_clean_room.py`.

## Decision and approver

Option 2 approved by the repository sponsor's instruction for bCodex, acting as Senior Architect, to proceed through the next governed plan without waiting for a separate human execution step. This decision authorizes research workspace controls only and does not authorize production implementation or source reuse.
