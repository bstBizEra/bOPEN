# /module-cycle

1. Register and classify the module.
2. Run `bopen-requirement-to-work-item`.
3. Run `bopen-module-contract`.
4. Architecture/security review.
5. Authorized implementation in isolated worktree.
6. Contract, integration and tenant-isolation verification.
7. Portal verification where applicable.
8. Evidence and independent review.
9. Pilot or remediation recommendation.
