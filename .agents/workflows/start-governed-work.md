# /start-governed-work

1. Run `bopen-governance-check`.
2. Read the work item and linked artifacts.
3. Produce a plan with files, risks, tests and stop conditions.
4. Wait for or confirm existing authorization.
5. Create/use the assigned isolated worktree.
6. Invoke the applicable implementation skill.
7. Run verification and `bopen-evidence-envelope`.
8. Send the structured handoff to the assigned checker.
