# Requirement to Work Item

Produce a work item using `templates/WORK-ITEM.md`.
Preserve requirement language and acceptance criteria.
Define allowed/prohibited paths, dependencies, risk, tests, evidence and stop conditions.
Do not authorize the work item; route it to Delivery Authority.
