# PostgreSQL Schema Difference Coverage

Evaluate schemas, tables, columns, data types, defaults, nullability, identity/generated definitions, constraints, indexes, sequences, enums, views, materialized views, functions, triggers, policies, grants, ownership, schemas, extensions, partitions, publications, and dependencies.

The minimum P0 canonical model supports the most common object classes. Objects not fully parsed must be emitted as `unknown`, preserved in raw evidence, and routed to review.
