# Supply-chain records

- `sbom.spdx.json`: initial SPDX package/dependency SBOM.
- `provenance.intoto.jsonl`: unsigned in-toto/SLSA-shaped build statement; regenerated by the release packager.
- `release-manifest.json`: file inventory and source-tree digest; regenerated by the release packager.
- `SHA256SUMS`: generated at release time.

These records support review but are not proof of authenticity until produced and signed by an approved build identity.
