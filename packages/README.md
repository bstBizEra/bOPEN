# Packages Zone

**Status:** Draft preparation surface  
**Work package:** `SKEL-P0-01`  
**Owner:** Engineering Authority

## Purpose

Typed package roots used to establish build, lint, and test wiring.

## Preparation boundary

**Allowed now:** Private 0.x package manifests, documentation, and empty declaration roots.

**Prohibited now:** Runtime exports, domain algorithms, persistence models, stable APIs, or dependency publication.

Nothing in this zone is an approved or stable dependency. Promotion requires the applicable implementation gate, exact-SHA review, required negative tests, and attributable Human Engineering Authority disposition.
