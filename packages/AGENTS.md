# AGENTS.md — Reusable packages

This file supplements the root [`AGENTS.md`](../AGENTS.md). Root rules remain mandatory.

## Directory purpose

Packages must have one clear responsibility, explicit public API, semantic versioning intent and no dependency on application routes. Platform packages must remain industry-neutral. Foundation packages may be reused by industry packs but must not absorb industry workflow semantics.

## Required completion evidence

- applicable artifact, requirement, ADR and work-package IDs;
- tests or validation appropriate to the directory;
- documentation/contract updates;
- security and clean-room declaration;
- residual risks and blocked decisions.
